# 東坡穿越記・黃州一〇八二

> 一卷《寒食帖》的墨跡暈開，你醒來時，身在九百多年前的長江邊。

一款繁體中文、手機優先的互動網頁遊戲。玩家穿越回北宋元豐五年（1082）的黃州，和被貶的蘇軾一起種田、淋雨、燉肉、夜遊赤壁。你的每個選擇會影響「知己值」與「樂觀值」，走向四種不同結局。

**誠實聲明：本作沒有使用任何生成式 AI。** 蘇軾的每句話都是事先寫好的劇本；「自由提問」只是關鍵字比對的固定回覆，問不到的時候他會老實說聽不懂。

## 功能

| 功能 | 說明 |
| --- | --- |
| 💬 劇情對話 | 序章＋五章＋終章的分支劇本：臨皋初見、東坡躬耕、寒食苦雨、沙湖遇雨、赤壁泛舟。打字中動畫、可調速度（一般／快／瞬間），點對話區可跳過等待。 |
| 🎭 四種結局 | 依知己值、樂觀值與是否接對〈定風波〉判定：千古知音（隱藏）、雪堂留名、一樽還酹、江上清風。 |
| ✍️ 接詞挑戰 | 劇情中要猜出〈定風波〉的下一句，選對有隱藏加分。 |
| 🔎 自由提問 | 輸入任何句子，比對約 30 組關鍵字給出固定回覆（東坡肉、子由、烏臺詩案、赤壁、佛印……），明確標示「關鍵字應答」。 |
| 🍲 東坡廚房 | 依〈豬肉頌〉「少著水、慢著火、待他自熟莫催他」燉肉：選水量、選火力，鍋蓋蓋上後看不到進度，憑感覺抓火候；偷掀鍋蓋會扣分。 |
| 📜 詩詞拾句 | 14 題題庫、每輪隨機 5 題，選項隨機排列，每題附出處與寫作年代。 |
| 🎒 行囊 | 結局圖鑑、14 枚印章（成就）、每日一支「東坡籤」、分享旅程、清除紀錄。 |
| 🥚 彩蛋 | 首頁連點月亮；向東坡透露「未來」（承天寺、荔枝、海南、蘇堤……）他會嚇一跳；故意把肉燉焦也有印章。 |
| ℹ️ 說明 | 玩法、史實／虛構標示說明、蘇軾生平簡表、參考資料。 |

## 史實與虛構如何區分

- <kbd>史</kbd> 紅底：引自蘇軾原文，或有史料依據。點一下對話泡泡可展開出處。
- <kbd>創</kbd> 綠框：本作虛構的對白或情節；若化用原文，同樣附上原句。
- <kbd>箋</kbd>「史實小箋」卡片：穿插在劇情中，補充真實歷史背景（如烏臺詩案、黃州赤壁不是三國古戰場、辣椒北宋還沒傳入）。
- 東坡籤的籤詩是原句，「解籤」則標為虛構。
- 「東坡肉」命名、佛印鬥嘴等屬後世傳說，遊戲中都有註明。

## 技術

- 純 HTML + CSS + JavaScript，沒有框架、沒有建置步驟、沒有後端、沒有付費 API。
- 進度、結局、印章存在瀏覽器 `localStorage`（無痕模式下可玩但不會保存）。
- 唯一外部資源：Google Fonts 的 Noto Serif TC（載入失敗會退回系統襯線字）。
- 手機優先（375px 起），電腦上以置中卡片呈現；支援 `prefers-reduced-motion`。

```
index.html      頁面結構
css/style.css   視覺樣式（宣紙米色＋朱砂紅；赤壁章節切換夜間配色）
js/data.js      劇本、結局、印章、關鍵字庫、題庫、籤詩、生平表
js/app.js       對話引擎、廚房、拾句、行囊等所有互動邏輯
```

## 本機執行

直接用瀏覽器開 `index.html` 即可；或在資料夾內啟動任一靜態伺服器，例如：

```bash
npx http-server -p 8080
```

## 測試紀錄

在 Chromium（行動 375×812 與桌面 1280×800）以腳本＋手動方式測試：

- 四種結局皆可達成（千古知音、雪堂留名、一樽還酹、江上清風），全部 14 枚印章皆可取得。
- 劇情中途重新整理後「繼續上次的旅程」：回到該段落開頭重播，數值正確還原。
- 自由提問：關鍵字比對、英文單字邊界（「this」不會誤中「hi」）、無對應時的備援回覆、未來彩蛋計數。
- 東坡廚房：滿分（少水＋文火＋區間內起鍋）、燒焦、偷看扣分。
- 詩詞拾句全對、每日籤、分享、清除紀錄。
- 主控台無錯誤。
